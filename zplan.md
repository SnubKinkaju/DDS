1. Réservations	Choisir des dates, demander un séjour, accepter ou refuser, éviter les réservations qui se chevauchent.
2. Facturation	Générer une facture liée au séjour, avec numéro unique, lignes, total et commission.
3. XML + XSD/DTD	Générer et valider les factures de la nouvelle application.
4. XSLT	Transformer ces factures XML en HTML et en version imprimable.
5. Export global + XPath	Exporter toutes les factures dans un XML et démontrer des recherches.
6. Texte libre + LLM	Transformer une description de logement en JSON validé pour préremplir le formulaire.
7. Dimension climatique	Ajouter les informations utiles : altitude, ombrage, équipements contre la chaleur, météo et services proches.
